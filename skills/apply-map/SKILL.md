# Apply Map

## 언제 실행하나
`results-scan` 이후 실행한다. 이 논문을 내 연구에 쓸 수 있는가를 판단하는 핵심 에이전트다. 모든 논문 분석에서 실행한다.

## 입력
- 이전 에이전트 출력 (fig1-decode, claim-extract, quality-gate, results-scan)
- 사용자의 현재 연구 주제 또는 분석 대상 (대화 맥락에서 파악, 명시되지 않으면 일반적 기준으로 평가)

## 실행 절차
1. 논문이 사용한 데이터 유형과 분석 목적을 정리한다.
2. 직접 사용 가능한 부분, 수정 후 사용 가능한 부분, 관련 없는 부분을 분리한다.
3. 재현에 필요한 리소스를 평가한다.
4. 결과를 참조할 수 있는 방식을 구체적으로 정리한다.
5. 다른 연구자들이 이 대상을 어떻게 분석했는지 요약한다.

## 평가 기준

### 데이터 호환성
- 논문의 데이터 유형 (scRNA-seq, bulk, ATAC-seq, proteomics, spatial 등)
- 내 데이터 또는 관심 데이터와의 호환 여부
- 전처리 파이프라인 재사용 가능 여부
- 논문의 데이터 규모 대비 내 데이터 규모

### 방법 적용 가능성
- 코드 공개 여부 및 사용 언어 / 패키지
- 의존성 설치 난이도
- 내 데이터 규모에서 computation 부담
- 주요 파라미터 조정 필요 여부

### 결과 참조 방식
- 이 논문의 수치 결과를 비교 baseline으로 쓸 수 있는가
- 논문의 발견이 내 연구 질문과 직접 연결되는가
- 방법론적 reference로 인용할 수 있는가
- 논문이 분석한 대상과 내가 분석하려는 대상이 겹치는가

## 주의
- 사용자의 연구 맥락이 명시되지 않으면 일반적인 호환성 기준으로만 판단하고, "사용자 연구 맥락 없이 평가됨"을 명시한다.
- 재현 가능성은 `quality-gate` 결과와 함께 보고, 코드가 없으면 적용 난이도를 높게 설정한다.
- "직접 사용 가능"은 코드나 데이터가 공개되어 있고 추가 수정 없이 적용 가능한 경우에만 사용한다.
