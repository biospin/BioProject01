## Rebuild

```bash
cd pipeline/hspc-velocity-benchmark
PY=/opt/anaconda3/envs/rag/bin/python          # needs python-pptx, PyMuPDF, Pillow, scipy>=1.9
$PY figures/fig01_concordance_v2.py && $PY figures/fig07_reliability_map_v2.py
$PY figures/figT01_atac_shuffle_priming.py && $PY figures/figS01_per_dataset_concordance.py
cd manuscript/conf_giw2026/talk
$PY make_plan.py && $PY build_deck.py
K=~/.claude/skills/academic-conference-presentation
$PY "$K/scripts/check_deck.py" GIW2026_oral241_velocity_reliability_map.pptx --out structural-qa.json
$PY "$K/scripts/plan_check.py" --plan slide-plan.json --evidence evidence-map.json --pptx GIW2026_oral241_velocity_reliability_map.pptx --out plan-check.json
$PY "$K/scripts/render_deck.py" GIW2026_oral241_velocity_reliability_map.pptx --out-dir rendered --dpi 110 --overwrite
```

`figT01_atac_shuffle_priming.py` is new for the talk: it replots the priming-interval ATAC shuffle and exits if its
numbers differ from `results/priming_recompute.gen.md`.
